운영 설정

설정을 적용하면 정책 유효기간은 30일로 갱신됩니다. 구버전 유예 종료일은 유지됩니다.

지원 버전

최신 버전은 업데이트 안내에 사용하고, 최소 지원 버전과 차단 목록은 이용을 제한합니다.

구버전 업데이트 유예

버전 정보를 보내지 않는 기존 앱을 기한까지 허용합니다. 점검과 허용 목록은 그대로 적용됩니다.

비워두면 구버전을 허용하지 않습니다.

배포 파일 등록

EXE를 업로드한 다운로드 주소와 이 PC의 파일이 일치하는지 확인합니다. 여기서는 배포 파일을 서버에 게시하지 않습니다.
