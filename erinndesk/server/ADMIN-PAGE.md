# Erinn Desk 로컬 관리 페이지

## 실행

`관리페이지.cmd`를 더블클릭하면 브라우저에서 관리 페이지가 열립니다.
실행한 콘솔 창을 닫거나 Ctrl+C를 누르면 관리 페이지 서버가 종료됩니다.

PowerShell에서 직접 실행할 수도 있습니다.

```powershell
cd D:\Project\mabinogi-mobile-info\erinndesk\server
.\관리자도구.ps1 web
```

또는 `python admin_web.py`를 실행합니다. 브라우저를 자동으로 열지 않으려면 `--no-browser`를 붙이고 콘솔에 나온 주소로 접속합니다.
Python/cryptography가 없는 PC에서는 먼저 `python -m pip install -r requirements-admin.txt`를 실행합니다.

## 최초 서버 준비

이 페이지는 기존 운영 API를 사용합니다. 서버 코드 배포와 관리자 Secret 등록 전에는 준비 안내를 표시하고 편집을 막습니다.
필요한 최초 준비는 [OPERATIONS.md](OPERATIONS.md)의 관리자 키 백업·Secret 등록·서버 배포 절차를 따르세요.
이 페이지에서 서버 배포, Secret 등록, 파일 업로드 게시, 관리자 키 초기화·백업을 실행하지 않습니다.
기존 CLI와 같은 DPAPI 암호화 인증정보를 재사용하며 관리자 토큰이나 비밀키를 다시 입력하지 않습니다.

## 사용 흐름

1. **운영 현황**에서 서버 응답·배포 커밋·정책 번호와 만료까지 남은 일수를 확인합니다.
2. **버전 관리 / 기능 점검 / 허용 사용자**에서 필요한 내용을 편집합니다. 탭을 옮겨도 작성 내용은 유지됩니다.
3. 하단 **변경 내용 확인**을 누릅니다. 이 단계에서는 운영 서버를 변경하지 않습니다.
4. 현재 값과 변경할 값을 비교한 뒤 **운영 서버에 적용**을 누릅니다.
5. 적용 결과가 불확실하면 재적용하기 전에 새로고침으로 실제 서버 상태를 확인합니다.

창을 새로고침하거나 변경 취소를 누르면 작성 중인 내용은 확인을 거쳐 버립니다.
브라우저를 닫거나 관리 도구를 다시 시작하면 미적용 입력은 복구되지 않습니다.

## 화면별 기능

- **운영 현황**: Cloudflare Workers 서비스 주소·응답·배포 커밋, 최신/최소 버전, 정책 만료일, 구버전 유예 기한, 기능 상태, 유효기간 갱신.
- **버전 관리**: 최신/최소 버전, 특정 버전 차단, 제한 범위, 업데이트 안내, 한국시간 구버전 유예 종료, 배포 EXE 검증과 등록.
- **기능 점검**: 디스코드 전체·신규 연결·아이템 조회·스크린샷의 사용 여부와 점검 문구.
- **허용 사용자**: 전체 허용 / 허용 목록만 / 전체 점검. Discord 사용자 ID와 관리 메모 추가·제거. 사용자 메모는 관리용이며 Discord 계정을 자동 조회하지 않습니다.
- **변경 이력**: 최근 100개 이전 설정 확인·복원 미리보기. 복원은 작성 중인 다른 변경을 합치지 않고 선택한 이력을 새 정책으로 적용합니다. 알려진 배포 파일 기록은 유지합니다.

CPU/RAM 할당 변경, Cloudflare 과금·트래픽·로그 조회와 GitHub 배포 실행은 포함하지 않습니다.

## EXE 등록

다운로드 파일을 기존 배포 저장소에 먼저 게시한 뒤, 버전·이 PC의 최종 EXE·직접 다운로드 HTTPS 주소를 선택합니다.
페이지는 선택한 파일을 로컬 서버로 전달해 SHA256을 계산하고 게시된 파일과 비교합니다.
파일을 실행하거나 별도 보관하지 않습니다. 서버에 다운로드 파일을 업로드하는 기능도 없습니다.
최대 파일 크기는 512MB입니다. 동일 버전의 SHA256/크기는 바꿀 수 없으며 다른 파일은 새 버전으로 등록해야 합니다.
검증 결과를 목록에 추가해도 아직 운영에 반영되지 않습니다. 변경 내용 확인과 최종 적용을 거쳐야 합니다.

## 로컬 접근과 적용 보호

- 서버는 `127.0.0.1`에만 바인딩합니다. 인터넷/다른 PC에서 접속하는 온라인 관리자 페이지가 아닙니다.
- 실행할 때 생성한 관리 세션이 포함된 주소로 브라우저를 엽니다. 세션은 URL의 fragment로 전달해 HTTP 요청에 남기지 않으며, 페이지가 읽은 뒤 주소창에서 제거합니다.
- 단순한 루트 페이지나 정적 파일에는 세션 토큰을 넣지 않습니다. API는 해당 실행의 세션 토큰·Host·Origin을 확인합니다.
- 세션은 브라우저 탭의 sessionStorage에 유지되어 같은 탭의 새로고침은 가능합니다. 관리 도구를 다시 실행했으면 새로 열린 주소를 사용합니다.
- 관리자 토큰과 서명 비밀키는 Python에서만 사용합니다. 브라우저 응답과 페이지 소스에 전달하지 않습니다.
- 정책은 적용할 때 로컬에서 서명합니다. 적용 미리보기는 3분 동안 유효하고 한 번만 적용할 수 있습니다.
- 다른 변경이 먼저 반영되면 정책 번호 검사가 충돌을 막습니다. 통신 오류가 나도 자동으로 재적용하지 않습니다.
- 응답의 CSP·Host 검사·외부 Origin 거절·세션 확인으로 외부 웹페이지 요청을 제한합니다. 앱 HTML을 외부 스크립트나 CDN에 의존하지 않습니다.
- 운영 서버 장애만으로 이미 작성한 입력을 자동으로 초기화하지 않습니다. 적용 실패 시 서버 상태를 확인한 뒤 재검토합니다.

## 검증

`python -m unittest discover -s test -p test_admin_web.py`: 로컬 접근 검사, 인증정보 미노출, 미리보기 무변경, 단일 적용, 충돌·만료, EXE 검증, 복원, 네트워크 오류 재실행 방지.

`python test/admin-web-ui.py`: Edge에서 실제 로컬 페이지를 사용하되 운영 서버 대신 메모리 상태로 편집·취소·적용·파일 검증·허용 사용자·복원·테마·초기 준비 안내를 확인합니다.

이 구현 검증 중 실제 운영 설정·등록 사용자·서명 키는 변경하지 않았습니다.


## 다운로드 주소 변경과 등록 상태 안내

배포 파일 표에는 버전별 다운로드 URL과 `주소 변경` 버튼이 표시됩니다.
주소 변경은 새 HTTPS 주소를 입력하고 등록된 SHA256·크기로 파일을 재검증합니다. 기존 EXE를 다시 선택할 필요는 없습니다.
검증 성공 후에도 아직 적용되지 않으며 하단 변경 내용 확인 → 운영 서버에 적용을 진행합니다. 최신 버전 선택은 자동 변경하지 않습니다.
아직 적용하지 않은 새 버전은 먼저 배포 정보를 적용해야 주소 변경 버튼을 사용할 수 있습니다.
파일 등록의 입력 오류·다운로드 실패·파일 불일치는 상단 알림 대신 파일 검증 버튼 옆에 빨간색으로 표시됩니다. 진행 중 안내와 성공 결과도 같은 위치에서 바뀝니다.
EXE 선택은 파일명 우측의 찾아보기 버튼으로 실행합니다.
이 변경을 반영하려면 관리 페이지 콘솔을 종료하고 관리페이지.cmd를 다시 실행하세요. Cloudflare 서버 배포나 앱 EXE 재빌드는 필요하지 않습니다.


### 디스코드 사용자 차단
- `디스코드 사용자 관리`에서 차단 사용자 ID, 관리자용 메모(100자), 사용자 안내 사유(선택, 300자)를 입력하고 추가합니다.
- `변경 내용 확인` 후 적용해야 서버에 반영됩니다. 목록 제거도 같은 절차로 적용합니다.
- 관리자용 메모는 관리 페이지 및 관리자 변경 이력에만 보관하며 일반 사용자에게 공개하지 않습니다.
- 사용자에게는 `디스코드 기능 이용이 제한된 계정입니다.`를 표시하며, 사유가 있으면 다음 줄에 `사유 : 입력한 내용`을 덧붙입니다.
- 전체 점검/기능 점검을 먼저 적용하고, 이후 차단 목록을 허용 목록보다 우선 적용합니다. 연결 해제는 계속 허용합니다.
- 기존 정책/이력에 차단 목록이 없으면 빈 목록으로 취급합니다. 과거 이력 복원 시 해당 이력의 차단 목록으로 돌아갑니다.
- 이 기능을 사용하기 전 변경된 Workers 서버를 배포하고 로컬 관리 페이지를 재시작하세요. 앱 재빌드는 필요하지 않습니다.


### 제한 없음 · 업데이트 권장
- 버전 조건(최소 지원/개별 차단/버전 미전송)을 이용 제한에 사용하지 않고 업데이트만 권장합니다. 기능 점검, 사용자 차단, 정책 유효기간, EXE 무결성 검사는 유지합니다.
- 내부 서명 정책은 구버전 앱도 해석할 수 있도록 scope=discord,minimum=0.0.0,blocked=[]와 별도 versionMode/versionAdvice로 게시합니다. 관리 화면/복원에서는 실제 선택한 none 및 원래 버전 조건으로 표시합니다. 다른 제한 범위로 바꾸면 보관했던 버전 조건이 다시 적용됩니다.
- 관리 페이지와 서버를 함께 업데이트해야 합니다. 관리자 도구를 재시작하고 서버를 배포한 뒤 사용하세요.
